# Japanese Kana Quiz

A Python-based command-line quiz for practicing Japanese hiragana and katakana.

Features

- 9 quiz modes covering hiragana, katakana, dakuten, handakuten, and yoon combinations
- Randomized questions without repetition within a round
- Romaji answer checking to test kana recognition
- Score tracking across quiz and retry rounds
- Retry missed characters to focus on areas that need more practice

Quiz Modes

1. Basic Hiragana
2. Hiragana Dakuten and Handakuten
3. Hiragana Yoon Combinations
4. All Hiragana
5. Basic Katakana
6. Katakana Dakuten and Handakuten
7. Katakana Yoon Combinations
8. All Katakana
9. Combined Hiragana and Katakana

Requirements

- Python 3

No external libraries are required.

How to Run

1. Download or clone this repository.
2. Open a terminal in the project directory.
3. Run:

   ```bash
   python kana_quiz.py
   ```

   Depending on your system, you may need to use `python3` instead.

4. Choose a quiz mode and enter the romaji corresponding to each kana character.

Purpose

This project was built as an independent Python learning project to practise programming fundamentals while creating a useful tool for studying Japanese.
